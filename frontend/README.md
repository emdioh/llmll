# LLMLL frontend

React + TypeScript + Vite PWA (mobile-first).

## Setup

    npm ci

## Development

Needs the backend running on http://localhost:8000 (`/api` is proxied there).

    npm run dev

## Scripts

    npm run build         # typecheck + production build into dist/
    npm run preview       # serve the production build
    npm test              # Vitest
    npm run lint          # ESLint
    npm run typecheck     # tsc -b
    npm run format        # Prettier (write); format:check to verify
    npm run gen:api       # generate src/api/schema.d.ts from the running backend's OpenAPI schema

PWA icons are generated by `node scripts/gen-icons.mjs` (output committed in `public/`).
